## Quick Reference / Practical Exam Cheat Sheet

| Tool | Command | Purpose |
|:---|:---|:---|
| **Git** | `git init` | Initialize local Git repository |
| **Git** | `git add .` | Stage all modified/new files |
| **Git** | `git commit -m "msg"` | Commit staged files |
| **Git** | `git push origin main` | Push commits to remote GitHub repository |
| **Git** | `git switch -c <branch>` | Create and switch to new branch |
| **Git** | `git merge <branch>` | Merge branch into current branch |
| **Jenkins** | `bat 'echo Hello'` | Execute Windows batch command in Jenkinsfile |
| **Jenkins** | `H/5 * * * *` | Schedule job execution every ~5 minutes |
| **Docker** | `docker build -t myapp .` | Build Docker image from Dockerfile in current dir |
| **Docker** | `docker run --rm myapp` | Run Docker container and auto-remove on exit |
| **Docker** | `docker run -d -p 8080:80 myapp` | Run container in detached mode with port mapping |
| **Docker** | `docker ps -a` | List all containers |
| **Kubernetes** | `kubectl apply -f manifest.yaml` | Apply deployment/service manifest |
| **Kubernetes** | `kubectl get pods,deploy,svc` | List all Kubernetes workloads |
| **Selenium** | `node test.js` | Run Selenium test script in Node.js |
