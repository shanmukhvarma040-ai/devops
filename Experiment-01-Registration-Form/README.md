# Experiment 1: User Registration Form for an Event

## Aim
Write code for a user registration form for an event with basic and additional input fields (Registration Form).

## Files
- `registration.html`: The HTML form with Name, Email, Phone, Gender, and Event fields.

## How to Execute
1. Open this folder in VS Code or File Explorer.
2. Double-click `registration.html` to open it in Google Chrome or any web browser.
3. Fill in all the fields (Name, Email, Phone, Gender, Event).
4. Click **Register**.

## Expected Output
Upon clicking **Register**, the text appears below the form:
```text
Registration Successful!
```
