# Experiment 9: Multi-Stage Pipeline Using Jenkins

## Aim
Implement a multi-stage pipeline using Jenkins.

## Job Name
`MultiStagePipeline`

## Pipeline Script
See `Jenkinsfile`.

## How to Execute
1. Create a Pipeline job named `MultiStagePipeline`.
2. Paste the script from `Jenkinsfile` and save.
3. Click **Build Now**.
4. Observe the Stage View in Jenkins showing Build -> Test -> Deploy.

## Expected Output
```text
Build Completed
Test Completed
Deploy Completed
Finished: SUCCESS
```
