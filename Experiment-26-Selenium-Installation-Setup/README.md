# Experiment 26: Download and Install Selenium for Automated Testing

## Aim
Download and install Selenium for automated testing.

## Prerequisites
- Node.js & npm installed (verify with `node -v` and `npm -v`)
- Google Chrome browser

## Setup Steps
```bash
npm init -y
npm install selenium-webdriver
```

## Verify Installation
```bash
npm list selenium-webdriver
```

## Expected Output
```text
selenium-lab@1.0.0
`-- selenium-webdriver@4.x.x
```
