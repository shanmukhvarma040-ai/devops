# Experiment 6: Create a GitHub Profile README

## Aim
Create a GitHub Profile README showcasing identity, skills, and activity using Markdown.

## How to Execute on GitHub
1. Open GitHub.
2. Click **New repository**.
3. Set the repository name to be **identical to your GitHub username** (e.g., `dshanmukhvarma`).
4. Set visibility to **Public** and check **Add a README file**.
5. Click **Create repository**.
6. Edit the `README.md` file and paste the profile content from `README.md`.
7. Commit changes.

## Expected Output
Your GitHub profile page prominently displays your portfolio, skills, projects, and contact info.
