# Experiment 21: Java Parameterized Constructor Using Docker

## Aim
Implement a parameterized constructor in Java using Docker.

## Files
- `Student.java`: Demonstrates parameterized constructor in Java.
- `Dockerfile`: JDK container to compile and run the application.

## How to Execute
```bash
docker build -t constructorapp .
docker run --rm constructorapp
```
